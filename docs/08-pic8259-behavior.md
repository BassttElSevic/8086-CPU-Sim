# 8259A PIC

`sim_pic.c` 模拟的是 PC 兼容的主从 8259A 中断控制器对。它是行为级模型，不是门级网表。

## 外部接口

- 主片端口：`20h` / `21h`
- 从片端口：`A0h` / `A1h`
- IRQ 输入：8 条逻辑中断请求线
- CPU 输出：INT 中断请求和 INTA 响应路径

## 主要功能

- 屏蔽寄存器 IMR；
- 请求寄存器 IRR；
- 在服务寄存器 ISR；
- 固定优先级和旋转优先级；
- 初始化命令字 ICW1-ICW4；
- 操作命令字 OCW1-OCW3；
- 特定/非特定 EOI；
- Poll；
- 主从级联；
- 8086 向量号响应。

## 运行方式

PIC 在总线读写中只在 T4 提交寄存器变化。IRQ 电平在每个内核周期采样一次。

`SIM_BUS_INTERRUPT_ACK` 事务用于两拍中断应答。第一拍锁存最高优先级请求，第二拍给出向量号。

## 现实差别

- 不模拟板级开集电极电气细节；
- 不模拟线上的传播延迟；
- 不模拟所有外部包线；
- 重点放在软件可见寄存器和优先级行为。
