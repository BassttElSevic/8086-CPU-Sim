# 8253/8254 PIT

`sim_pit.c` 模拟的是 PC 定时器。它按模拟时钟计数，不按宿主机壁钟直接跳变。

## 外部接口

- 端口 `40h`：计数器 0
- 端口 `41h`：计数器 1
- 端口 `42h`：计数器 2
- 端口 `43h`：控制字和读回

## 已建模内容

- 三个独立计数器；
- LSB、MSB、LSB+MSB 装载；
- 二进制计数和 BCD 计数；
- 锁存计数和锁存状态；
- Read-Back；
- Mode 0 到 Mode 5；
- GATE 输入；
- 计数到期后向 PIC 0 号 IRQ 线发脉冲。

## 时钟关系

PIT 有自己的计数频率。模拟器内核有自己的逻辑节拍。两者通过比例换算连接。当前默认用 1193182 Hz 对 4772728 Hz 的比例关系。
