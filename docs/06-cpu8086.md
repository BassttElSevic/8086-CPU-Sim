# 8086 CPU

## 结构

当前 CPU 按 8086 的工程分工拆成这些部分：

- `cpu8086_state`：寄存器、FLAGS、预取队列、BIU/EU 微状态；
- `cpu8086_decoder`：机器码到指令描述；
- `cpu8086_ea`：有效地址生成；
- `cpu8086_alu`：算术逻辑和标志位；
- `cpu8086_shifter`：移位和循环；
- `cpu8086_eu`：执行单元；
- `cpu8086_biu`：总线接口单元；
- `cpu8086_prefetch`：预取队列；
- `cpu8086`：顶层调度和外部接口。

## 运行方式

CPU 每拍先看 current，再在 next 里写结果。

BIU 负责取指和总线事务。EU 负责解释指令语义。两者共享同一套状态，但各自保存自己的阶段。

### 一个例子

`ADD AX, BX` 的过程分成几步：

1. BIU 维持预取；
2. EU 取出操作码并译码；
3. EU 读取 AX 和 BX；
4. ALU 计算结果和 FLAGS；
5. next 里的 AX 和 FLAGS 在上升沿写回。

## ISA 范围

当前实现覆盖 8086 上 BIOS 和 DOS 启动需要的指令集合，并包含常见的数据传送、算术逻辑、控制转移、堆栈、中断、串操作、标志控制、I/O 访问和部分 BCD 指令。

它保留 8086 的分段模型、物理地址形成方式、FLAGS 语义和总线访问习惯。
