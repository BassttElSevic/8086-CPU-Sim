# 启动器

## 作用

启动器是宿主机前端。它负责选择 BIOS ROM、软盘镜像、硬盘镜像，并显示 CGA 文本输出。

## 当前实现

启动器使用固定批次推进模拟器。它没有追求严格的实时时钟。

原因很直接：整机仿真和图形渲染一起跑时，Windows 线程调度跟不上理论上的每拍节拍。当前做法是给模拟器持续提供上升沿，让系统稳定跑完安装和交互流程。

## 用户可见功能

- 选择 BIOS ROM；
- 选择 A: 软盘镜像；
- 选择 C: 物理磁盘式原始镜像；
- 重载软盘镜像；
- 调整推进倍率；
- 显示 CGA 文本区；
- 接收键盘输入并送入模拟键盘控制器。

## 显示边界

启动器只渲染模拟 CGA 的已提交状态。窗口缩放只影响宿主显示，不影响模拟分辨率。
